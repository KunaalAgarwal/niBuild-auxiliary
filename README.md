# niBuild-auxiliary

Auxiliary **[niBuild](https://github.com/KunaalAgarwal/niBuild)** repository. 

See visualizations/ for the figures, and generating code, used in the **paper (in progress)** and [**poster**](https://github.com/KunaalAgarwal/works/blob/main/Agarwal_niBuild_UVA_Brain_Symposium.pdf). 

See validation/ for the workflow bundles and tutorials used in the fMRI flanker and VBM Alzheimer's analyses. We encourage trying to run these workflows yourself and comparing to the outputs we produced. 

See the **[documentation](https://kunaalagarwal.github.io/niBuild-auxiliary/)** for practical information on niBuild usage.
